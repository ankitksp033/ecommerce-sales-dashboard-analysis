# Project Report

## Objective
To analyze e-commerce sales performance and create an interactive dashboard for business decision-making.

---

## Workflow
1. Data Cleaning using Power Query
2. Data Transformation
3. KPI Development
4. Pivot Table Analysis
5. Dashboard Visualization
6. Business Insight Generation

---

## Dashboard Features
- Sales Performance Analysis
- Profitability Tracking
- Regional Analysis
- Customer Segment Analysis
- Discount Impact Analysis
- Monthly Trend Analysis

---

## Conclusion
The dashboard helps identify profitability trends, discount impact, seasonal sales behavior, and high-performing customer segments for strategic business decisions.
